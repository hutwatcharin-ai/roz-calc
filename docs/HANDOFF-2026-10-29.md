### พรีวิว → deploy
1. งานที่ผู้เล่นเห็นได้: ส่งลิงก์พรีวิว `http://100.108.70.113:3178/<path>` + ภาพหน้าจอก่อนทุกครั้ง
2. deploy เฉพาะเมื่อเจ้าของพิมพ์ "ขึ้น"
3. ขั้นตอน deploy:
   - `git push` ต้องเห็น `master -> master` ถ้า push ไม่ติด ห้าม deploy
   - รัน deploy แบบซ่อนผ่าน PowerShell `Start-Process node -ArgumentList @('scripts/deploy.mjs','--path','<page>','--expect','"<ข้อความที่มีเฉพาะในบิลด์ใหม่>"') -WorkingDirectory D:\Web\roz-calc -WindowStyle Hidden -RedirectStandardOutput <scratch>\x.log -RedirectStandardError <scratch>\x.err`
   - ห้ามใช้ `cmd /c` กับข้อความไทย
   - marker ต้องไม่มีในบิลด์เก่า (เคยรายงานสำเร็จผิดเพราะ marker มีอยู่แล้ว)
   - log บอก "purge failed" ให้รัน `npm run purge`
   - เช็กด้วย `curl --ssl-no-revoke` แล้วแปะลิงก์ rozerothai.com ของทุกหน้าที่เปลี่ยน
4. หลัง `npm run build` รีสตาร์ต 3177/3178: หยุด pid ที่ฟังพอร์ต (Get-NetTCPConnection) แล้ว `Start-Process cmd /c "npx next start -p <port> -H 0.0.0.0"` ซ่อนหน้าต่าง WorkingDirectory `D:\Web\roz-calc`
5. ก่อนเช็กหน้าที่อ่าน DB ให้ลบ `.next/cache/fetch-cache` (Next data cache ซ่อนค่าใหม่ อาการเหมือนโค้ดพัง)
