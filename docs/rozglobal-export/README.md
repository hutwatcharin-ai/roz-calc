# roz-global.info mirror, 8 Sep 2026

A French-language Ragnarok Zero Global guide site (by poulpi_x), fetched with
the user's own request on 8 Sep 2026. robots.txt is `Allow: /` and the site
publishes a sitemap; all 33 pages it lists are mirrored under `pages/`, and
`tables.json` holds the 82 HTML tables pulled out of them.

**What this is for.** It is a map of what a Zero player wants explained that
we do not cover -- memorial-dungeon gear, enchanting, star weapons, which
card goes in which slot -- not a source to copy. The prose is one person's
writing and reusing it would be plagiarism; the numbers are one source and
this site's rule is two. Everything taken from here gets checked against our
own tables, the prontera crawl, the rozerodb export or rAthena before it is
published, and it gets written in our own words in Thai.

- `urls.txt` — the sitemap's 33 URLs
- `pages/` — the raw HTML as fetched
- `tables.json` — every table, as `{caption, rows}` per page
