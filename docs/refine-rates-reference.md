# ตารางอัตราตีบวก Ragnarok Zero Global — ข้อมูลอ้างอิงจาก rozerodb

วันที่เก็บ: 26 สิงหาคม 2569
ที่มา: หน้า `/tools/refine` ของ rozerodb.com โดยค่าตัวเลขอยู่ในไฟล์ JavaScript แบบ static ของหน้านั้น ไม่ได้มาจาก endpoint `/api/` ที่ robots.txt ของเขาห้ามไว้

> **สถานะ: ข้อมูลอ้างอิง ยังไม่ยืนยัน** ตัวเลขทั้งหมดคือสิ่งที่ rozerodb แสดง เว็บของเขาเองระบุว่าค่าอัตราสำเร็จมาจากเอกสาร Global อย่างเป็นทางการ แต่กลไกแร่และผลของการตีบวกเกิน +10 ต้องไปอ้างอิงจาก Ragnarok Zero เกาหลี เพราะฝั่ง Global ไม่ได้เอกสารไว้ครบ ก่อนนำขึ้นเว็บต้องตรวจซ้ำในเกมหรือจากไฟล์เกมก่อน

## ตารางอัตราสำเร็จ

ตัวเลขในช่องคือ **แร่ธรรมดา / แร่เข้มข้น (Concentrated)** หน่วยเป็นเปอร์เซ็นต์

- **Weapon Lv.1 และ Lv.2 ง่ายที่สุดในช่วงปลาย** ขั้น +11 ถึง +20 ยังอยู่ที่ 15–18% ขณะที่เกราะเหลือ 5–8%
- แร่เข้มข้นทำให้ขั้น +1 ถึง +4 ติด 100% และช่วยมากที่สุดที่ขั้น +5 ถึง +9
- ขั้น +10 คือกำแพงจริง เกราะเหลือ 9% ส่วนอาวุธเบา ๆ ยังได้ 19%

## แร่และค่าธรรมเนียมตามช่วงขั้น

| ช่วงขั้น | ตัวเลือกแร่ | ผลเมื่อพลาด |
| --- | --- | --- |
| +1 ถึง +6 | ธรรมดา หรือ เข้มข้น | ของแตก |
| +7 ถึง +9 | ธรรมดา / เข้มข้น / **HD** | HD พลาดแล้ว **ลดระดับตีบวกลง 1 ขั้น** ไม่แตก |
| +10 ขึ้นไป | over-refine ธรรมดา หรือ over-refine HD | ตามชนิดแร่ |

ชื่อแร่ต่างกันตามชนิดของ: เกราะใช้สาย Elunium อาวุธใช้สาย Oridecon

ค่าธรรมเนียมต่อครั้งตามระดับอาวุธ:

| ของ | แร่ | ค่าธรรมเนียม |
| --- | --- | --- |
| Weapon Lv.1 | Phracon (ซื้อ NPC 200 เซนี) | 1,000 เซนี |
| Weapon Lv.2 | Emveretarcon (ซื้อ NPC 1,000 เซนี) | 2,000 เซนี |
| Weapon Lv.3–4 และ Armor | Oridecon / Elunium (ดรอปหรือซื้อจากตลาด) | 10,000 เซนี |
| แร่ HD | แลกที่ NPC | 20,000 เซนี |

**ส่วนที่ rozerodb ระบุว่าอ้างอิงจากเกาหลี ไม่ใช่ Global:** สูตรคราฟต์แร่เข้มข้นและแร่ over-refine (เช่น แร่เข้มข้น = แร่ธรรมดา 1 + Gelstar 1 + 500,000 เซนี ส่วนแร่ over-refine ใช้ Gelstar 4–5 และเงินหลักล้าน) รวมถึงชื่อแร่ over-refine ตระกูล Bradium / Carnium ทั้งหมดนี้ยังไม่ยืนยันว่าตรงกับ Global

**จุดที่ยังไม่รู้:** ตัวเลือกแร่เข้มข้นของ Weapon Lv.1 และ Lv.2 ในเว็บของเขาขึ้นป้ายว่า "Special" โดยไม่ระบุชื่อแร่

## ปิดข้อขัดแย้งที่ค้างไว้จากงานวิจัยคลิป

ใน `youtube-research-roz.md` หัวข้อ "ข้อมูลที่ยังขัดกัน" ข้อ 1 บันทึกว่าสองช่องพูดอัตราตีบวกไม่ตรงกัน ตารางนี้ตัดสินได้:

- **NCZ พูดถูก** — +1 ถึง +3 ที่ 90%, +4 ที่ 80%, +5 ที่ 60% ตรงกับสาย **Armor และ Weapon Lv.4** เป๊ะทั้งสามค่า
- **Viva-Tz ที่บอกว่า +1 ถึง +4 ติด 90% เท่ากันหมด** ไม่ผิดเสียทีเดียว เพราะตรงกับสาย **Weapon Lv.1, Lv.2 และ Lv.3** ซึ่ง +4 ยังอยู่ที่ 90% จริง

สรุปคือทั้งคู่พูดถูกคนละสาย และต้นตอของความสับสนคือ **อัตราตีบวกใน Zero ขึ้นกับประเภทและระดับของของที่ตี ไม่ใช่ตัวเลขชุดเดียวทั้งเกม** ซึ่งเป็นสิ่งที่ไม่มีคลิปไหนพูดถึงเลย

จุดที่ทั้งสองคลิปพูดตรงกันและตารางนี้ยืนยัน คือ **ของแตกได้ตั้งแต่ขั้นแรก** (ยกเว้นใช้แร่ HD ในช่วง +7 ถึง +9 ที่ลดขั้นแทนแตก)

## โบนัสที่ได้จากการตีบวก (ถอดครบแล้ว 26 ส.ค.)

อาร์เรย์สองชุดที่ค้างไว้ในรอบแรกถอดออกมาได้แล้ว ทั้งคู่คือค่าโบนัสของอาวุธ ไม่ใช่ค่าใช้จ่าย

### อาวุธ — โบนัสพื้นฐาน

เพิ่มขึ้นเป็นเส้นตรงตามระดับอาวุธ ขั้นละ:

| ระดับอาวุธ | โบนัสต่อขั้น (ขั้น +1 ถึง +15) |
| --- | --- |
| Lv.1 | +2 |
| Lv.2 | +3 |
| Lv.3 | +5 |
| Lv.4 | +8 |

เช่น Weapon Lv.4 ที่ +5 ได้โบนัสพื้นฐาน +40 ส่วน Lv.1 ที่ +10 ได้ +20

ตั้งแต่ขั้น +16 ขึ้นไปอัตราเร่งขึ้นชัดเจน ไม่เป็นเส้นตรงอีกต่อไป ปลายทางที่ +20 อยู่ที่ +120 / +220 / +370 / +595 ตามระดับอาวุธ

### อาวุธ — โบนัสสุ่มเพิ่ม

นอกจากค่าพื้นฐานแล้วยังมีค่าสุ่มเพิ่มในรูปแบบ "+1 ถึง +N" โดย N โตขึ้นเรื่อย ๆ ตามขั้น และ **เริ่มมีที่ขั้นต่างกันตามระดับอาวุธ**

| ระดับอาวุธ | เริ่มมีค่าสุ่มที่ขั้น | N เพิ่มขั้นละ |
| --- | --- | --- |
| Lv.4 | +5 | 14 |
| Lv.3 | +6 | 8 |
| Lv.2 | +7 | 5 |
| Lv.1 | +8 | 3 |

เช่น Weapon Lv.4 ที่ +5 ได้ "+40 บวกอีก +1 ถึง +14" และที่ +20 ช่วงสุ่มขยายเป็น +1 ถึง +224

**นัยสำคัญ:** อาวุธระดับสูงไม่ได้แค่โบนัสพื้นฐานมากกว่า แต่ได้ค่าสุ่มเร็วกว่าและกว้างกว่ามาก — ของชิ้นเดียวกันที่ +9 เท่ากันจึงแรงไม่เท่ากันได้ ซึ่งเป็นเหตุผลที่ตลาดให้ราคาต่างกันแม้เลขตีบวกเท่ากัน

### เกราะ

ไม่มีตารางแยก ใช้สูตรตรง ๆ คือ **โบนัสเท่ากับขั้นยกกำลังสอง** (+5 ได้ 25, +10 ได้ 100, +20 ได้ 400)

## ชื่อแร่ครบทุกประเภท

| ประเภท | เกราะ | อาวุธ |
| --- | --- | --- |
| ธรรมดา | Elunium | Phracon (Lv.1), Emveretarcon (Lv.2), Oridecon (Lv.3–4) |
| เข้มข้น | Concentrated Elunium | Concentrated Oridecon |
| HD (ใช้ช่วง +7 ถึง +9) | HD Elunium | HD Oridecon |
| Over-refine ธรรมดา (+10 ขึ้นไป) | Carnium | Bradium |
| Over-refine HD | High-Density Carnium | High-Density Bradium |

ตระกูล Carnium / Bradium และรุ่น High-Density คือส่วนที่ rozerodb ระบุเองว่าอ้างอิงจาก Zero เกาหลี เพราะ Global ไม่ได้เอกสารกลไกแร่ over-refine ไว้

## ที่ยังเหลือ

- ตารางโบนัส MATK แยกจาก ATK หรือใช้ค่าเดียวกัน ยังไม่ได้ตรวจ
- ค่าใช้จ่ายรวม (จำนวนแร่ที่ต้องใช้จริงต่อการพยายามหนึ่งครั้ง) ไม่มีในชุดข้อมูลนี้ มีแต่ค่าธรรมเนียมเป็นเซนี

## ใช้กับโปรเจกต์อย่างไร

ตามที่สรุปไว้ใน `rozerodb-tools-audit.md` โปรเจกต์ยังไม่ควรทำ Refine Simulator เป็นฟีเจอร์ของเว็บ และไม่ควรเอาตารางนี้ขึ้นหน้าเว็บสาธารณะ ให้ใช้ในสองทางนี้แทน:

1. **เป็นชุดตรวจสอบ** เมื่อวันหนึ่งดึงค่าจากไฟล์เกมได้เอง เอามาเทียบกับตารางนี้ ถ้าตรงกันแสดงว่าอ่านไฟล์ถูก ถ้าไม่ตรงคือมีอย่างหนึ่งผิดและต้องหาว่าอันไหน
2. **เป็นข้อมูลประกอบการเขียนไกด์** โดยเฉพาะประเด็นที่ว่าอัตราตีบวกขึ้นกับระดับของ ซึ่งผู้เล่นเข้าใจผิดกันอยู่ — อธิบายหลักการได้โดยไม่ต้องลอกตารางทั้งชุด
