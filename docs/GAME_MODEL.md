## 2. เส้นทางผู้เล่น

- **เก็บเลเวลด้วยบอท** เป็นหลัก ทุกอาชีพ ทุกไกด์เลือกแมพจาก "เปิดบอทได้ไหม" ไม่ใช่ "EXP สูงสุด" [คลิป]
- เส้นทางตัวอย่าง (Archer→Hunter จากไกด์เรา, อาชีพอื่นคล้ายกัน) [คลิป]:
  - 1-9 เควสเนื้อเรื่องต้นเกม → 9-15 Spore แถว Payon → 15-20 Prontera Sewer 2 → 20-30 Creamy/Smokie Geffen → 30-40 Coco / Ant Hell → 40-50 Orc Village / Steel Chonchon
  - **Base 50 เปลี่ยนอาชีพขั้น 2** [เจ้าของเว็บ] (prontera.info บอก Job 40 — ผิด) · ไม่มีระบบ Ascension/High class
  - 50-60 Nordfeld Cave 2F (ต้อง Lv 50 เข้าได้) คนแน่น มอนน้อย
- กติกาที่กระทบการเลือกจุด [คลิป]: **ไม่มีขั้นบันได EXP** (ตีห่างเลเวลแค่ไหนก็ได้เต็ม) · **หักดรอป 50% ถ้าห่างเกิน ±40** (±19 ไม่โดนอะไร) · ตายเสีย EXP 10% (บัฟลดเหลือ 5%)
- มอนต้นเกม hit 200-300 → ทำ FLEE ~250 ก็แทบไม่โดนตี = เหตุที่ **FLEE เป็นเมตาต้นเซิร์ฟ** และเป็นแกนของเซ็ตบอท [คลิป][ตลาด FB]
- ปลายเกมตอนนี้: Memorial Dungeon (ชุดดัน), MVP Raid, WoE, ฟาร์มของออปดีขาย [ทางการ][ตลาด FB]
- **ลูปหลังเลเวล 60** [คลิป: GanGGap / Zeztz, ก.ย. 2026 — สูง: หลายคลิปตรงกัน]: ลงดันความทรงจำเลเวล 60 สองแห่ง (Orc's Memory, Prontera Culvert) **วันละครั้ง** เข้าคนเดียวได้แต่ปาร์ตี้ 7 คนขึ้นไปได้ของเพิ่ม → เก็บชุดเซ็ตเลเวล 60 → **อัปเป็นชุดเลเวล 70** ได้ (ตีบวกกลับ 0) → เอาชุดไป "ทำออฟ/ส่อง" หาออป ทำพังได้ (กลับมาไม่มีออป ต้องทำใหม่) · Sage เคลียร์ได้คนเดียว [คลิป: เลเวล 60 Dungeons with Sage Solo]
- ตั้งค่าเกมเริ่มต้นไม่โชว์ EXP ที่ได้ ต้องเปิดในตั้งค่าแชท [คลิป]
- **มือใหม่ 1-50** [คลิป: Viva-Tz, ส.ค. 2026 — กลาง]: เควสเก็บเลเวลต้นเกมแจกหมวกสีเหลือง (MaxHP/SP) และให้เลือกเสื้อ ของเควสพวกนี้มีออป 1-3 บรรทัด (เลือกตัวที่ออป MaxHP/FLEE) · ของสวมใส่จากแคชไม่จำเป็น ของในเกมดีกว่า · ที่คุ้มคือ Essential Package (~80-90 บาท: อาวุธประจำอาชีพ +7 ATK/MATK +20 + บัฟ All Stat 7 / ATK MATK +30 / FLEE +5 ครั้งละ 1 ชม.) · มีทดลองเล่นฟรี 3 วัน (ถึง ธ.ค. 2026 ตามคลิป) · ช่วงเปิดเซิร์ฟ (ส.ค.) ตันที่ 50/50 ใช้ราว 15-20 วัน

### ช่องไหนติดออปชันได้ (Global)
- อาวุธ, เสื้อ, ผ้าคลุม, รองเท้า, **หมวก, เครื่องประดับ** — ได้ [ตลาด FB] (ตารางไต้หวันบอกหมวก/ประดับไม่มี — **ผิดสำหรับ Global**)

  - หมวก: HIT/FLEE +20, CRI 6, AGI 3, MaxHP/ATK, กันกึ่งมนุษย์ 10%

## 8. กับดักที่ผมเคยพลาด (กฎถาวร — เพิ่มทุกครั้งที่เจ้าของเว็บแก้)
- **เรียกว่า "สุ่ม" ไม่ใช่ "ทอย"** — ผู้เล่นพูดว่าสุ่มออปชัน / สุ่มติด ใช้คำนี้ทุกที่บนเว็บ [เจ้าของเว็บ 26 ก.ย.]

- **"ใส่ได้" ≠ "เขาใส่กัน"** — Hunter ใส่มีดได้แต่ไม่มีใครใส่ เครื่องมือต้องใช้อาวุธที่อาชีพเล่นจริง (`lib/job-weapons.ts`)
- **ออปชันคือของ ตัวไอเทมคือฐาน** — ช่องอาวุธ Hunter ไม่ว่างเพราะไม่มีธนูให้ FLEE ในตัว คำตอบคือ "ธนูอะไรก็ได้ที่สุ่มติด FLEE"
- **ของเควสติดออปได้ใน Global** — กฎ "สุ่มได้เฉพาะของดรอป" จากตารางไต้หวันผิด · ตารางไต้หวันใช้เป็นแหล่งรองเท่านั้น
- **อย่าบวกค่าออปสูงสุดให้ชุดที่จัด** — ใช้ค่าที่เห็นขายบ่อย · อย่าหยิบการ์ด MVP / ของติดดาว / อาวุธตีเอง ในชุดที่ "จัดให้"
