### 1.7 ค้นหาฉลาดทั้งเว็บ (commit `14dcaf7`, `c1f324a`)

**วัดก่อนทำ**: ดึง search term จริงจาก GA4 (511 ครั้ง/60 วัน) มายิงซ้ำกับ DB → **76 ครั้ง (17%) ได้ศูนย์**

`lib/smart-search.ts` = กติกาเดียวใช้ทุกช่อง:
- `matchScore` เรียง: ตรงเป๊ะ 100 > คำแรกตรง 90 > ขึ้นต้นด้วย 80 > คำในชื่อขึ้นต้น 70 > มีอยู่ 60 > ครบทุกคำไม่สนลำดับ 50
- `similarity` = ค่าที่ดีกว่าระหว่าง **นับคู่ตัวอักษร (Dice)** กับ **ระยะแก้ไข (Levenshtein)** — ต้องใช้ทั้งคู่เพราะนับคู่อย่างเดียวให้ `graud`→`guard` ได้ **0 เต็มๆ** (สลับตัวอักษรทำลายทุกคู่)
- `lib/search-catalog.ts` โหลดชื่อทั้งเว็บ **เฉพาะตอนค้นไม่เจอ** → เสนอ "เจอในหมวดอื่น" (ตรงจริง) แล้วค่อย "หรือหมายถึง" (เดา)
- หน้าที่ page ฝั่ง server (มอน/ไอเทม) ใช้ ilike ทีละคำ AND กัน → `potion red` เจอ Red Potion

ตัวอย่างที่แก้ได้จริง: `muffer`→Muffler · `damacus`/`damarcus`/`darmacus`→Damascus · `Gukkung`→Gakkung Bow · `clip` (ในหน้าไอเทม)→Clip (อุปกรณ์) · `Desert Wolf Card` (ในหน้ามอน)→Baby Desert Wolf Card

**ช่องค้นรวมกลับมา** (user สั่ง ไม่เอาคีย์ลัด): ปุ่ม 🔍 มุมขวาบน · ค้น 7 หมวดพร้อมกัน · ตัดชื่อซ้ำต่อหมวด (เดิม `orc` ขึ้น Orc Village 3 บรรทัดเพราะแมพ 3 ช่อง) · Escape ปิดกล่องได้ (เป็นพฤติกรรมของ dialog ไม่ใช่ทางเข้า)

## 3. บทเรียนวันนี้ — อ่านก่อนทำงานต่อ

1. **`--expect` ของ `npm run deploy` ต้องเป็นข้อความที่มีเฉพาะในของใหม่**
   วันนี้ใส่ "ค้นหาทุกอย่าง" ซึ่งมีอยู่แล้วจาก deploy รอบก่อน → สคริปต์เจอทันที บอกว่าสำเร็จ ทั้งที่ Coolify ยังบิลด์ไม่เสร็จ **รายงาน user ผิดไป 1 ครั้ง**
2. **อ่านผลสคริปต์ deploy ให้ครบ** — บรรทัด `gave up waiting for the origin` ตามด้วย `told Telegram` เหมือนกัน เคยอ่านผิดแล้วรายงานว่าขึ้นแล้วทั้งที่ build ล้ม
3. **คำสั่งแก้ไฟล์ด้วย python replace ต้อง assert เสมอ** — วันนี้ replace ตัวหนึ่งไม่เข้า (ไฟล์จริงมีคอมเมนต์เกิน) แต่ `tsc` ไม่ฟ้องเพราะ import ที่ไม่ได้ใช้ไม่ใช่ error → เกือบรายงานว่าแก้แล้วทั้งที่ยังพัง จับได้เพราะไปคลิกจริงในเบราว์เซอร์แล้วนับ
4. **อย่าด่วนสรุปจากตัวเลขในรายงาน** — เห็น `http://rozerothai.com` ใน GSC 146 ครั้ง แล้วบอก user ให้ไปเปิด Always Use HTTPS พอยิงเทสต์จริงพบว่า **301 อยู่แล้วทั้งหมด** ตัวเลขนั้นเป็นข้อมูลย้อนหลัง
5. **replay กับข้อมูลจริงก่อนสรุปว่าอะไรพัง** — รอบแรกสรุปว่าหน้าการ์ดค้นเอฟเฟกต์ไม่ได้ พอไปอ่านโค้ดจริงพบว่าค้นได้อยู่แล้ว ต้องแก้ตัวเลขที่รายงานไป
6. **เน็ต VPS วันนี้ไม่นิ่ง — deploy ล้ม 5 ครั้ง** (npm install ECONNRESET ×2, fonts.googleapis ×1, github ×2) ล้วนไม่เกี่ยวโค้ด สั่งซ้ำผ่านทุกครั้ง
