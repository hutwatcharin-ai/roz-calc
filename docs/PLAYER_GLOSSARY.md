# ศัพท์ที่คนเล่น RO ไทยใช้จริง

อ้างอิงก่อนเขียนคำบนหน้าเว็บ (user, 7 ก.ย. 2569: "กริช = มีด ใช้ มีด นะ คนเล่นเรียกแบบนี้ … ไปหาคำที่คนในเกมใช้มา").
ที่มา: ตารางขนาดอาวุธของ rainelix.blogspot.com (2014), บทความ kamonway.com (2016, 2018), gitbook ROC 4.0 — คำที่ตรงกันอย่างน้อย 2 แหล่งจึงเอามาใช้

## คำกริยา/ศัพท์ทั่วไป
- เก็บเลเวล = level up · ฟาร์ม = farm · ตีบวก = refine · เจาะ(รู) = slot enchant · Slot = ช่องการ์ด (คงคำว่า Slot ตาม CLAUDE.md)
- ดาเมจ, สกิล, สเตตัส (status/stat), ค่าสเตตัส, มอน = monster, บอส/MVP, ดรอป, แมพ
- ตีโดน / หลบ / มันตีเราโดน — ใช้ตรงๆ แบบนี้ ไม่ใช้ "แม่นยำ" "ความแม่น"
- จำนวนครั้งโจมตี = "ตีกี่ที" (ไม่ใช่ หมัด) · สายเวท = "ร่ายกี่ครั้ง"
- กึ่งมนุษย์ = Demi-Human
